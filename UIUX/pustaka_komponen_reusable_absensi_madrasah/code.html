3. Tombol (Buttons)

Hanya 3 varian esensial: Primary, Secondary, Text Button. Tinggi sentuhan nyaman (44px Android tap target).

Variants: primary | secondary | text
Primary Button

Digunakan untuk aksi utama seperti "Absen Datang", "Simpan Presensi", "Konfirmasi Siswa".

Secondary / Outline Button

Digunakan untuk aksi pendukung seperti "Batal", "Download Template", "Filter Tanggal".

Text Button

Digunakan untuk navigasi inline ringan seperti "Lihat Detail", "Ajukan Koreksi", "Reset".

Pedoman Sentuhan: Semua tombol memiliki tinggi minimum h-11 (44px) untuk menjamin kenyamanan sentuhan jari pada smartphone guru Android.
