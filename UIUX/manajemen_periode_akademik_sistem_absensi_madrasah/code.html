Kepatuhan Aturan Bisnis Presensi Madrasah

BR-036: Isolasi Periode Aktif

Tepat satu periode berstatus is_active = true. Mesin presensi GPS & QR menolak pencatatan jika tidak ada periode aktif.

FS-PERIOD-003: Proteksi Integritas

Data kehadiran pada periode terdahulu diarsipkan secara permanen. Tidak dapat ditimpa atau dihapus saat tahun ajaran baru diinisiasi.

Data Model: Partial Index

Ditegakkan oleh constraint database Postgres: CREATE UNIQUE INDEX ON academic_periods (madrasah_id) WHERE is_active = true.
